DA-RestClient: REST-Endpunkte einfach und schnell testen

Für einen kurzen API-Test muss es nicht immer eine umfangreiche Entwicklungsumgebung sein. DA-RestClient ist eine kleine Desktop-Anwendung, mit der sich REST-Endpunkte unkompliziert aufrufen und überprüfen lassen. Eine Anfrage wird direkt als Text eingegeben. Die erste Zeile enthält die HTTP-Methode und die URL, danach folgen bei Bedarf Header und Request-Body. Mit F5 wird die Anfrage gesendet. HTTP-Status, Response-Header und Antwortinhalt erscheinen übersichtlich im unteren Editor. Gültige JSON-Antworten werden automatisch formatiert.

Einfache Textdateien statt proprietärer Projekte

DA-RestClient speichert jede Anfrage als normale .rest-Textdatei. Ein Projekt ist lediglich ein Ordner mit Dateien und Unterordnern. Dadurch bleiben alle Anfragen transparent und können auch außerhalb der Anwendung gelesen oder bearbeitet werden. Die Dateien lassen sich wie Quellcode verwalten: Sie können kopiert, gesichert, durchsucht und mit Git versioniert werden. Änderungen bleiben nachvollziehbar und komplette Request-Sammlungen können einfach gemeinsam mit einem Projekt abgelegt werden.

Eine Anfrage in wenigen Zeilen

POST https://example.com/api/items
Content-Type: application/json
Authorization: Bearer TOKEN

{
  "name": "Example"
}
Unterstützt werden unter anderem GET-, POST-, PUT-, PATCH- und DELETE-Anfragen sowie individuelle Header, Query-Parameter und Request-Bodys.

Auf das Wesentliche konzentriert

DA-RestClient kommt ohne große Frameworks, Benutzerkonto oder Cloud-Speicher aus. Die native Anwendung ist klein, startet schnell und konzentriert sich auf die Funktionen, die beim Testen von REST-Endpunkten tatsächlich benötigt werden. Damit eignet sich DA-RestClient für Entwickler, Tester und Administratoren ebenso wie für alle, die gelegentlich eine API prüfen möchten. Die Anwendung ist kostenlos nutzbar.
